# Roadmap ESTOKI WMS

## 🎯 Visão

Construir o melhor sistema WMS open-source do Brasil.

## 📅 Q1 2025

### Janeiro
- [ ] Integração completa com Correios API
- [ ] App mobile PWA
- [ ] Dashboard gerencial avançado

### Fevereiro
- [ ] Integração com marketplaces (Mercado Livre, Amazon)
- [ ] Sistema de picking por voz
- [ ] Relatórios personalizáveis

### Março
- [ ] Multi-tenant
- [ ] API pública documentada
- [ ] Integração com ERPs (SAP, TOTVS)

## 📅 Q2 2025

- [ ] Machine Learning para previsão de demanda
- [ ] Otimização automática de rotas de picking
- [ ] Integração com AGVs e automação
- [ ] App nativo iOS/Android

## 📅 Q3-Q4 2025

- [ ] Expansão internacional (suporte multi-idioma)
- [ ] Marketplace de plugins
- [ ] Certificação SOC 2
- [ ] Enterprise features
